# note-雅舍小品(读书笔记 skill)

来源:《雅舍小品》,梁实秋 著。初版于 1949 年(抗战时期以"雅舍"为号在《星期评论》《世纪评论》等连载结集),后有大陆多家出版社重印本,本书目据"跟大师学语文 / 写作的书"整理本。

完整抽取结果见 [`references/note.md`](references/note.md):含导览、全书思维导图(序 + 34 篇结构)、核心论点 / 心智模型 / 论证证据 / 反例边界、金句摘录,以及"与我连接 / 可执行下一步 / 未解问题 / 评价与适合人群"通用模板。块 1–4、导览、大纲、金句忠于原书;块 5–7 与评价为读者自填的通用示范。
