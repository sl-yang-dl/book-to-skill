# 《写作这回事》读书笔记

> 七块骨架抽取 · 来源:斯蒂芬·金《写作这回事》(张坤译)
> 块 1–4 忠实抽取;块 5–7 留给读者本人填写。另含导览 / 金句 / 评价三个通用块。

## 导览 · 全书脉络与书目

- 书名 / 作者 / 译者 / 版本:《写作这回事:创作生涯回忆录》(On Writing: A Memoir of the Craft),斯蒂芬·金 著,张坤 译。
- 阅读日期 / 阅读目的:(读者填)
- 一句话总结:一半自传、一半写作匠艺课——用"工具箱"和"关门写、开门改"把"写作靠天赋"打成"写作是门手艺"。
- 全书结构地图:
  - 第一部「关门写作,开门改稿」(C.V.):金的自传,从童年到成为作家,穿插早年写作与酗酒经历。
  - 第二部「书目 / 工具箱」(On Writing):核心匠艺——词汇、语法、语态三层工具箱;"关门写作、开门改稿"的进程观。
  - 第三部「补充再补充」:1999 年车祸与康复,写作如何帮他活过来;对写作者的最终叮嘱。

## 1. 核心论点(Core Arguments)
- 写作是可严肃对待的技艺,不是天赋玄学;"要命的写作"值得你正经地谈,做不到就"去做点别的"(比如去洗车)。
- 写作者要自建"工具箱"并随身带:词汇、语法、语态是基本素材,越常用越放上层。
- 进程观:"关门写作,开门改稿"——先写初稿不回头自我审查,再大改。
- 诚实表达优先:有话直说,用想到的第一个恰当且生动的词,拒绝粉饰语汇(别给宠物穿晚礼服)。

## 2. 心智模型(Mental Models)
- **工具箱模型**:写作者是木匠,工具箱分多层抽屉;常用工具(词汇)放最上层,并"增强肌肉力量"才有力气随身带。
  奥伦姨父的教训:"最好把工具带在身边。不然你如果碰到意料之外的问题,就很容易会因为没准备而气馁。"(§工具箱)
- **安全网模型**:"岩石爆炸。珍发报。山漂浮。"——任何名词 + 任何动词即一个合格句子;语法是让思想站稳脚跟的竿子,不是牢笼。(§工具箱/语法)
- **进程模型**:关门写作(不自我审查)→ 开门改稿(大改)。(目录:第一部"关门写作,开门改稿")

## 3. 论证证据(Evidence)
- 词汇:引海明威"他来到河上。河就在那里。"、斯特金、费尔拜恩的极简句;对照洛弗克拉夫特 / 麦卡锡的繁复句,说明"你有多少不重要,怎么使用才重要"(妓女对水师语:"甜心,怎么使用才重要")。(§工具箱/词汇)
- 语法:名词 + 动词即句子(岩石爆炸);斯特伦克"作者除非确认自己写得很好,否则最好遵守规则"。(§工具箱/语法)
- 语态:主动式主语在做某事,被动式主语被施加动作;胆怯的作者爱用被动(像被动的伴侣),应尽量避免。(§工具箱/语态)
- 进程:目录明确分"第一部:关门写作,开门改稿 / 第二部:书目 / 第三部:补充再补充"。

## 4. 反例边界(Counterexamples / Boundaries)
- 不必总是写完整句:"你的作品如果完全由片语和断句构成,不会有语法警察来把你抓走";斯特伦克也认可"最好的作家有时置规则于不顾"。(§工具箱/语法)
- 语法不必精通:"就像我学不会用吉他演奏某些乐句……这样的一本书对他可能压根没什么用处";高二语法不及格也能写。重点在"名词 + 动词"这个安全网。(§工具箱/语法)
- 礼貌 / 适宜也要考虑(乔治·卡林例子):用词第一规矩是"适宜且生动",并非裸奔;选词时可考虑礼貌。(§工具箱/词汇)
- 被动语态并非绝对禁用,只是"尽量避免";权威感(手册、律师函)常用被动,作者只是不推荐。(§工具箱/语态)

## 金句摘录(Quotable Lines)

- "最好把工具带在身边。不然你如果碰到意料之外的问题,就很容易会因为没准备而气馁。"(§工具箱,奥伦姨父的教训)
- "岩石爆炸。珍发报。山漂浮。"——任何名词 + 任何动词就是一个合格句子;语法是让思想站稳的竿子,不是牢笼。(§工具箱/语法)
- "甜心,怎么使用才重要。"(妓女对水师语,喻词汇量不重要、用得好才重要)(§工具箱/词汇)
- "别给宠物穿晚礼服。"——拒绝粉饰语汇,用想到的第一个恰当且生动的词。(§工具箱/词汇)
- "写初稿时把门关上,改稿时把门打开。"(目录:第一部"关门写作,开门改稿")
- "如果你写不出像样的东西,就去干点别的——比如去洗车。"(喻写作是可严肃对待的技艺,不是天赋玄学)

## 5. 与我连接(Connections)—— 以下为通用示例,读者按自己情况改写
- 可与自己已有的写作书收藏 / 读过的创作谈对照:金的"工具箱 + 有话直说"补的是更底层的**姿态**:别端着、别粉饰。它和修辞训练不是对立,而是前置——先诚实,再修辞。
- 和本项目的七块骨架互相印证:"可执行下一步"(块6)本质就是金的"关门写作、开门改稿"——先产出再打磨,不要边写边自我审查。这份笔记 skill 本身也可视作个人写作工具箱的一层抽屉。
- 金说"词汇量你大可满足于已有的"——与"靠多读补语感"的路线形成对照:两条路各有道理,可思考自己偏哪边。

## 6. 可执行下一步(Actionable Next Steps)—— 以下为通用示例,读者按自己情况改写
- [ ] 仿"工具箱"给自己建一个写作工具箱清单:词汇(禁用的粉饰词)、语法(主谓齐全的安全网)、语态(主动优先)各列 3 条铁律,放在笔记或常看处。
- [ ] 下次动笔先"关门写作"写满初稿,再统一改稿,**不在写的过程中回头改**(治边写边自我审查的毛病)。
- [ ] 写初稿时刻意用"想到的第一个词",禁止换大词"提升档次",改稿阶段再考虑文气。

## 7. 未解问题(Open Questions)—— 以下为通用示例,读者按自己情况改写
- 金强调"有话直说、拒绝粉饰",但很多大家在讲修辞与文气,二者边界在哪?是不是"先金后修辞"?还是某些文体本就不该极简?
- 工具箱模型对**非虚构 / 学术写作**是否同样适用?还是更偏叙事 / 小说?自己常写的文体(公众号 / 工作文档等)算哪边?
- 他说"高二语法不及格也能写",那到底要不要补语法?痛点更可能在"结构 / 逻辑"而非"词汇"时,工具箱该往哪层加重量?

## 评价与适合人群(Verdict)

- 总体评分 / 一句话评价:匠艺启发 9/10,纯写作技法 7/10。最打动人的是"写作是手艺不是魔法"的姿态,以及用自身血泪(车祸)证成的"写下去";但它教的是姿态与纪律,不是系统的修辞语法。
- 适合谁读:想克服"我写不好"心魔的人;喜欢作家自传 / 创作谈的读者;需要写作纪律(先写后改)的人。
- 不适合谁 / 局限:想要"如何把句子写漂亮"的语法风格手册,应去读《一本小小的红色写作书》;想要故事 / 情节结构法,去读 McKee《故事》。
- 延伸对照:与《红色写作书》互补(金给姿态,罗伊尔给说明书);与 McKee《故事》不同尺度(金在字词 / 纪律层,McKee 在故事层)。
