# 读书笔记模板(七块骨架 · 扩展版)

> 由 book-to-skill reader 使用。把一本书填进下面结构。
> 核心七块:块 1–4 忠实抽取(忠于原书,不加个人发挥);块 5–7 综合块(读者本人填写)。
> 另含 3 个通用块:导览(全书脉络 + 书目)、金句摘录、评价与适合人群。

## 导览 · 全书脉络与书目(faithful 抽取)
- 书名 / 作者 / 译者 / 版本:
- 阅读日期 / 阅读目的:
- 一句话总结:
- 全书结构地图(分几部分、每部分讲什么,便于回查):

## 1. 核心论点(Core Arguments)
这本书最根本的主张是什么?用 3–7 条要点概括。
- 

## 2. 心智模型(Mental Models)
作者提供的、可复用的思维 / 行动框架。优先来自书里标志性的比喻或结构(如"工具箱""三步法")。
- 模型名:描述 + 何时用

## 3. 论证证据(Evidence)
支撑上述论点的关键例子、原书引文、数据。标注出处章节以便回查。
- 

## 4. 反例边界(Counterexamples / Boundaries)
作者自己承认的例外、明确说"不适用于"的情形、或你读出的适用边界。
- 

## 金句摘录(Quotable Lines)—— faithful 抽取
写推文 / PRD / 笔记时最想直接抄的原句。每条附出处章节。
- 原书原句(§出处章节)

## 5. 与我连接(Connections)—— 自选,读者填
它和我已有的知识 / 项目 / 习惯有什么关系?
- 

## 6. 可执行下一步(Actionable Next Steps)—— 自选,读者填
基于这本书,我具体能做的一件小事?

我哪里不同意?还想追问什么?
